# Подборка удачных и проблемных ответов

Файл собран командой `python src/triage_baseline.py run`. Подборка детерминирована: успех — NDCG@3 равен 1, провал — NDCG@3 равен 0, карточки берутся по кругу из сценариев.

Успех по правилу означает, что все три позиции заняли карточки с оценкой не ниже 1, то есть совпала услуга или причина. Совпадения обеих меток в индексе нет, поэтому успешный ответ не равен «нашлась та же причина и та же услуга».

«Слова с вкладом» — разложение косинусного сходства по словам: видно, на чём держится похожесть. «Причина» перечисляет совпадения меток в выдаче. Механизмы отказа перечислены в `README.md`, номера совпадают.

Механизмы в подборке: 3 — 20. Механизмы 1, 2, 4 не встретились.
