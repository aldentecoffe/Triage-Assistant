# Разрезы baseline

Файл собран командой `python src/eval_report.py run`. Число запросов в каждой строке указано явно: без знаменателя сегмент с 96 запросами и сегмент с 559 выглядят одинаково убедительно. Столбец NDCG@3 по шкале ЛР 7 оставлен для сверки с опубликованными метриками baseline: у этих двух чисел разная шкала, сравнивать их между собой нельзя, только видеть, в какую сторону они разошлись.

## Разброс по сценариям

Разброс между шаблонами важнее среднего: если минимум близок к нулю, среднее по всем запросам описывает не систему, а долю удачных шаблонов.

- минимум средних: 0,147 (SC-BSS-01), максимум средних: 0,803 (SC-BIL-02); размах 0,656
- стандартное отклонение средних по сценариям: 0,256
- средняя NDCG@3 по всем запросам: 0,413
- разница сигналов и средняя NDCG@3 по сценариям коррелируют на 0,857: там, где причина ближе услуги, поиск работает
- медиана ранга лучшей карточки той же причины — 15: нужное рядом, но ниже отсечения
- сегмент P1 целиком лежит в сценарии SC-IMS-03: все 96 карточек — услуга ims, причина software. Строка P1 в таблице серьёзности повторяет строку этого сценария, а не измеряет серьёзность.
