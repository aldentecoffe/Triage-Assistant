## Счёт вручную

Gain равен 2 в степени оценки минус 1, дисконт позиции равен log2(позиция + 1), позиции считаются с единицы. Слагаемые: 3/1,00000 = 3,00000; 1/1,58496 = 0,63093; 0/2,00000 = 0,00000. Сумма — 3,63093.

В индексе 514 карточек с той же причиной и 514 карточек той же услуги с другой причиной, поэтому идеальный порядок — [2, 2, 2] с полезностью 3/1,00000 + 3/1,58496 + 3/2,00000 = 6,39279.

NDCG@3 = 3,63093 / 6,39279 = 0,568. MRR@3 по этому запросу равен 1,000.

## Проверка вырожденных случаев

Если поменять местами первые два результата, оценки станут [1, 2, 0], полезность 2,89279, то есть NDCG 0,453: порядок наказывается, но не обнуляется.

Пустая выдача даёт NDCG, Recall и MRR, равные нулю, и учитывается отдельным столбцом «Пустых», а не нулём в среднем. Это проверяется тестом на пустой строке и на `k = 0`, чтобы ошибка агрегирования не скрылась за средним.
