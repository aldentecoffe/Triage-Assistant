## Переранжировщик: проверка риска «частая причина»

Точность top-1 на validation: 0,369 на 1 200 запросах. Классификатор обучался только на train; его ответ не используется в оценке релевантности, только как сигнал сортировки.

| Причина запроса | Запросов | Точность top-1 |
|---|---|---|
| capacity | 172 | 1,000 |
| change | 342 | 0,532 |
| external_dep | 171 | 0,000 |
| hardware | 172 | 0,326 |
| software | 343 | 0,096 |

Сигнал насыщен классом `capacity`: argmax — capacity у 862 из 1 200 запросов (72 %). Причина `external_dep` не распознана ни разу. Прирост 0,067 при этом распределён по причинам: change — 0,028, capacity — 0,015, software — 0,012, hardware — 0,009, external_dep — 0,003. Насыщение ограничивает интерпретацию сигнала, но не объясняет весь эффект.

## Что проверка не покрывает

- Причины в validation: capacity, change, external_dep, hardware, software. Вне проверки осталась причина network: она есть в train, но не в validation.
- Сценариев в validation: 7; P1 — только SC-IMS-03. Защитный показатель P1 измеряет знакомство с лексикой одного сценария.
- Языки: ru: 938, en: 262. Английские запросы есть, но их меньше, и отдельного порога для них не задано.
- Запросов без релевантных карточек в индексе: 0. Правило исключения из среднего записано в работе 8 и здесь не пересматривается.
- Длина описания и редкие интерфейсы отдельными сегментами не проверялись: их разбор остался в работе 8.
