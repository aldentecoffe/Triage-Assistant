# Листы полного объёма: 120 + 30

Дополнительный набор для пилота в объёме, который просит методичка (100–150 карточек).
Основной пилот 30 + 10 уже размечен и посчитан, его листы лежат на уровень выше; этот
набор пока не заполнен и в отчётах не используется.

| Файл | Что внутри |
|---|---|
| `pass_a.csv` | 120 карточек из train и validation, первый проход |
| `pass_b.csv` | 30 карточек из первого листа, второй (отложенный) проход |
| `form_a.html`, `form_b.html` | те же карточки в форме: списки, прогресс, выгрузка CSV |
| `key.csv` | соответствие «номер карточки → incident_id», открывать после второго прохода |

Выборка: 21 сценарий из train и validation (15 сценариев дают по 6 карточек, 6 — по 5),
карточки-примеры из инструкции исключены, test не используется.

## Как заполнять

1. Открыть `form_a.html`, разметить 120 карточек, выгрузить `pass_a.csv` в эту папку.
2. Через сутки или позже открыть `form_b.html`, разметить 30 карточек, выгрузить `pass_b.csv`.
3. Пересчитать согласие:

```bash
python src/agreement.py --labels data/annotation/full
```

Правила — в [инструкции разметчика](../../../docs/lab6/annotation_guideline.md).
После заполнения оба файла коммитятся, а результаты пилота обновляются в
[annotation_results.md](../../../docs/lab6/annotation_results.md).
