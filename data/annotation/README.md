# Листы пилотной разметки

Артефакт лабораторной 6. Листы созданы командой `python src/annotation_sheet.py`
и пересоздаются с `--force`.

| Файл | Что внутри |
|---|---|
| `pass_a.csv` | 120 карточек из train и validation, первый проход |
| `pass_b.csv` | 30 карточек из первого листа, второй (отложенный) проход |
| `form_a.html`, `form_b.html` | те же карточки в локальной форме: списки, прогресс, выгрузка CSV |
| `key.csv` | соответствие «номер карточки → incident_id», открывать только после второго прохода |

В листах видны только номер карточки и описание. Метки, `scenario_id`, `event_id`, сервис
и причина в лист не попадают: иначе проверялась бы память о сгенерированных метках,
а не инструкция.

## Как заполнять

Проще всего через форму: откройте `form_a.html` двойным щелчком в браузере. На карточку
приходятся три списка, уверенность и комментарий; стрелки влево-вправо листают карточки,
цифры `1`–`4` ставят критичность. Прогресс сохраняется в браузере, вкладку можно закрыть.
Кнопка «Скачать CSV» отдаёт файл с именем `pass_a.csv`; положите его в эту папку, заменив
исходный. Со вторым проходом то же самое, только `form_b.html`.

Если правите CSV вручную, правила — в [инструкции разметчика](../../docs/lab6/annotation_guideline.md).
Коротко:

- `severity`: `P1`, `P2`, `P3`, `P4` или `спорный`;
- `service`: `transport`, `platform`, `database`, `ims`, `billing`, `bss`, `external`;
- `root_cause`: `change`, `capacity`, `hardware`, `software`, `network`, `external_dep`;
- `confidence`: 1–3, где 3 — правило применимо без оговорок;
- `comment`: обязателен для «спорного» и для уверенности 1.

CSV пишется в UTF-8 с BOM, Excel открывает его без настройки кодировки; сохранять нужно
в тот же формат: `CSV UTF-8 (разделитель — запятая)`.

## Когда оба прохода готовы

```bash
python src/agreement.py
```

Скрипт считает долю совпадений и каппу Коэна между проходами, сверяет каждый проход
с метками набора и печатает журнал расхождений. Результат переносится в
`docs/lab6/annotation_results.md`; этот файл появляется только после обоих проходов.
